# split_tunneling

Scripts that reproduce the calculations of the split tunneling resonance between twisted monolayer Ising
superconductors (1H-NbSe₂, TaS₂). The steps, their inputs and their outputs are listed in the calculation-pipeline
table of the paper (Supporting Information, Section S8); this README only explains how to run them.

No data files are included: every input is generated by the scripts. The folders `runs/` (DFT work files),
`contours/` (Fermi contours) and `results/` (outputs) are created when the scripts run.

## Requirements

- Python ≥ 3.9 with NumPy and SciPy (`pip install -r requirements.txt`)
- [Elk](https://elk.sourceforge.io) (all-electron FP-LAPW code), only for step 1

## Files

| file | content |
|---|---|
| `dft_elk.py` | Elk ground state (PBE + spin–orbit coupling), band structures on rays from Γ, Γ-pocket Fermi crossings and velocities → `contours/NAME.json` |
| `contour.py` | contour model: symmetry-adapted fit, contact geometry, G_N and I_c, broadening law, current density, device imperfections |
| `tb.py` | three-band tight-binding model of 1H-NbSe₂ |
| `junction.py` | tight-binding tunnel junction: weak tunnelling, exact in the tunnelling amplitude, umklapp channel |
| `reproduce.py` | one command per result (below) |

## How to run

**1. DFT Fermi contours** (Elk; a few hours per material on two cores)

```
python dft_elk.py NbSe2 --species <elk-species-folder>
python dft_elk.py TaS2  --species <elk-species-folder>
```

Optional: `NbSe2_h1.656` (relaxed chalcogen height), and `--rgkmax 9 --tag rgk9` or `--nk 42 --swidth 0.00025 --tag k42`
for the convergence checks. Use `--elk` if the Elk executable is not called `elk`.

**2. Contour model** (seconds to about ten minutes per command; reads `contours/*.json` and adds the tight-binding contour)

```
python reproduce.py contact        # contact angle (exact and leading order), Ising slope, harmonics; spread over admissible fits and Fermi-level shifts
python reproduce.py peaks --fits   # split-peak positions and contrasts of G_N and I_c, I_cR_N, for gamma = 2, 5, 10, 20 meV
python reproduce.py law            # peak offset and height against gamma, effective exponents, cubic law, scaling function
python reproduce.py maps           # angular current density on the Gamma contour at 60 deg, the contact and the split peak
python reproduce.py window         # band offset, Rashba texture, heterostrain, twist spread, incoherent current, contact size, CDW
python reproduce.py leak           # coupling of the opposite-spin branches
python reproduce.py joint          # all imperfections in one calculation
```

**3. Tight-binding junction** (hours)

```
python reproduce.py tb-scan --jobs 4   # G_N, I_c and I_cR_N from 0 to 60 deg, spin-orbit coupling on and off
python reproduce.py tb-law             # broadening law of the full tight-binding junction
python reproduce.py tb-umklapp         # first-shell umklapp channel
python reproduce.py tb-exact           # exact in the tunnelling amplitude, coupling t = 1-20 meV
```

## Output

Each command prints a short summary and writes `results/COMMAND.json`. The printed quantities correspond to the
paper's material table (`contact`, `peaks`), the broadening law (`law`, `tb-law`), the current maps (`maps`), the
twist dependence in the tunnelling limit (`tb-scan`) and the conditions for observation (`window`, `leak`, `joint`,
`tb-umklapp`, `tb-exact`). All energies are in eV (printed in meV where noted), momenta in 1/Å and angles in degrees.
